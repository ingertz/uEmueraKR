# 성능

[← 목차](README.md)

<details>
<summary><b>로딩 시간</b></summary>

- ERB 파일을 미리 읽어 두면서 동시에 해석해서, 파일 수가 많은 게임의 로딩 시간을 줄였습니다.
- 캐릭터 CSV도 미리 읽어 둡니다(천 개가 넘는 게임이 있음).
- 게임 폴더를 한 번만 훑고 그 결과를 다시 써서, 같은 폴더를 여러 번 찾던 시간을 없앴습니다.

</details>

<details>
<summary><b>발열과 배터리</b></summary>

- 화면에 변화가 없으면 1초 뒤부터 그리는 횟수를 초당 24번에서 2번으로 줄입니다.
  화면을 만지거나, 글이 추가되거나, 스크립트가 실행 중이거나, 움직이는 그림이 있으면 바로 원래대로 돌아옵니다.
- 입력을 처리할 때마다 넣던 0.01초 대기를 없앴습니다.

</details>

<details>
<summary><b>아주 큰 게임은 함수를 불릴 때 읽기</b> (지연 로딩)</summary>

- ERB가 합쳐서 100MB 이상인 게임은, 시작할 때 함수의 이름과 머리줄(`@`줄, `#`줄)만 읽고 본문은 그 함수가 처음 불릴 때 읽습니다.
- 다 읽어 두면 ERB 한 줄에 400바이트쯤 메모리를 써서, TW 키메라팩(ERB 364MB, 940만 줄)은 4GB가 넘어 폰에서 로딩 중에 튕겼습니다.
  지연 로딩으로 읽은 직후 메모리가 약 200MB가 됩니다. PC용 EmueraLazyLoading이나 eraJS와 같은 방식입니다.
- 이 모드에서는 문법 오류가 있는 줄을 시작할 때 검사하지 않고, 그 줄을 실행할 때 오류가 납니다.
- 함수 본문을 처음 읽는 데 0.1초 넘게 걸리면 `uEmuera.log`에 남깁니다.

</details>
